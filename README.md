# SocketProgramming

Skeleton của LANLink Desktop, đồ án chat và truyền tệp qua TCP/UDP trong mạng LAN. Các tệp mã nguồn, kiểm thử và tài liệu được tạo sẵn để điền khi triển khai.

| Thư mục | Nội dung dự kiến |
| --- | --- |
| `backend/` | UDP discovery, kết nối TCP, giao thức, chat, truyền tệp và lưu dữ liệu |
| `frontend/` | Cửa sổ và thành phần PySide6, chủ đề QSS |
| `tests/` | Kiểm thử giao thức, socket và giao diện |
| `docs/` | Kiến trúc, đặc tả giao thức, báo cáo và hướng dẫn demo |
| `downloads/` | Thư mục nhận tệp |

`main.py` là vị trí dành cho điểm khởi động ứng dụng.
